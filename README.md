# Marketing Portfolio — Phung Minh Ngoc

Static marketing portfolio prepared for GitHub Pages.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static server.

## Structure
- `index.html` — page markup
- `styles.css` — responsive styling
- `script.js` — project data/rendering
- `public/images/` — portfolio assets

## GitHub Pages
In repository Settings → Pages, choose **Deploy from a branch**, then select **main** and **/(root)**.

Expected URL: `https://phungminhngoc5823.github.io/marketing-portfolio/`
